The Orchestra

Topic Description

This website will explore the orchestra and the elements that make it up. The orchestra is a large ensemble with many moving parts that have to come together to make music. It is important for any musician looking to add orchestral elements to their music to understand basic functions of the orchestra and the instruments that make it up. The orchestra can help fill out a song and add depth to a song if utilized correctly. However, to have the effect that a musician might want it to have, it is important to understand how the individual instruments work together to create a cohesive sound and how these instruments should be layered in a way that adds to a song instead of overpowering it.

There are many web apps that provide ways to learn about the orchestra such as the Kennedy Center's Guide to the Orchestra. and The Violin Channel's Guide to the Orchestra. My hope is that this website will delve into how everyday musicians can utilize the orchestra in their own music and provide a resource for those looking to learn more about the orchestra and how it can be used in modern music and different genres.

App Description

The Orchestra guide will eventually contain four main pages. The first page will be the home page which will contain a brief history and description of the orchestra and links to notable pieces of both classical and modern music that utilize the orchestra. It will contain images, links to pieces, a title, and navigation links to other pages of the site.

The second page will be a page that allows users to explore the different sections of the orchestra in two steps. The first step will show the user a list of the different sections and the second step will show the instruments that make up that section.

Step 1: Sections

  • Strings
  • Woodwinds
  • Brass
  • Percussion

Step 2: Instruments

  • Strings: Violin, Viola, Cello, Double bass
  • Woodwinds: Flute, Oboe, Clarinet, Bassoon
  • Brass: Trumpet, Horn, Trombone, Tuba
  • Percussion: Timpani, Snare Drum, Bass Drum, Cymbals

Clicking on the sections will show pictures of these instruments which the user can then click to bring up data about their frequencies, what they are good for, how they should traditionally be used, and other technical information that should be known. I want to brainstorm some interactive parts as well to insert such as demos of these instruments and other fun/helpful things but that might be a little ambitious.

Third page

This page will contain extra information about the anatomy of an orchestra, some music theory that composers use, and roles within an orchestra.

Fourth page

This will be a contact us page that will hold the users email, name, and comments, issues, or questions about the website and orchstra.
