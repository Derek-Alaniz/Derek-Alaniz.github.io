The String Family

The string family is one of the largest sections of a traditional orchestra. String instruments produce sound through vibrating strings and can be played with a bow or by plucking the strings.

Choose an Instrument

Select an instrument below to learn more about its role, sound, and characteristics.

Violin

The violin is the highest-pitched standard member of the string family. It is commonly used for melodies, harmony, and fast musical passages.

Learn About the Violin

Viola

The viola is slightly larger than the violin and has a lower, darker sound. It often fills the middle range of the string section.

Learn About the Viola

Cello

The cello has a rich lower register and can play both expressive melodies and supporting harmony.

Learn About the Cello

Double Bass

The double bass is the largest common orchestral string instrument and provides much of the low foundation of the orchestra.

Learn About the Double Bass
